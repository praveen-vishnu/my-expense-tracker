# PennyWise

PennyWise is a smart personal finance, liquidity, and expense tracker with monthly income, account balances, pacing, burn rates, credit card settlement, and Supabase sync.

## Development

```powershell
npm install
npm run dev
```

Build for production:

```powershell
npm run build
```

For Supabase setup, see [SUPABASE_SETUP.md](SUPABASE_SETUP.md). For versioning and publishing releases, see [RELEASE.md](RELEASE.md). The project history is maintained in [CHANGELOG.md](CHANGELOG.md).
